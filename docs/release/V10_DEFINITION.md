# v1.0 definition of done

SDN Sentinel v1.0 is complete when the following are true:

1. The authorized lab connects a Ryu controller to an OpenFlow 1.3 switch.
2. Baseline traffic is recorded before the experiment.
3. High-rate traffic generates structured detection telemetry.
4. The policy installs a time-bounded drop rule.
5. Switch counters verify the drop rule.
6. The dashboard displays topology, flow, detection, and evidence views.
7. The API protects telemetry and topology endpoints.
8. Tests, compilation, doctor checks, and release validation pass.
9. Documentation states the model and production boundaries accurately.
10. No secrets, virtual environments, or accidental embedded repositories are
   published.
