# Threat model

## In scope

- High-rate authorized traffic generated by Mininet hosts.
- Source-MAC flooding toward a lab victim.
- Controller-side detection and switch-level drop enforcement.
- Evidence integrity within the local experiment directory.

## Out of scope

- Internet-facing DDoS protection.
- Botnet attribution.
- Application-layer HTTP attacks.
- Spoofed source identity beyond the lab model.
- High-availability controller deployment.
- Automatic production changes.

## Controls

- Local-only experiment scope.
- Explicit runbook commands.
- No arbitrary shell execution in the dashboard.
- Timed mitigation rules.
- Structured event logs.
- Tests for topology and runtime contracts.
- Documentation of model schema limitations.
