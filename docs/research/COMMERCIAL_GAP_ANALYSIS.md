# Commercial gap analysis

## Current differentiator

Explainable, topology-aware, programmable mitigation with switch-counter proof.

## Required paid-pilot capabilities

- Persistent PostgreSQL/TimescaleDB storage.
- OIDC/SSO, MFA, password hashing, and RBAC.
- TLS for API, dashboard, and device channels.
- HA controller and rule reconciliation.
- Device enrollment and certificate rotation.
- Policy approval and rollback.
- Prometheus metrics and alerting.
- Signed audit records and retention.
- Docker/Kubernetes deployment.
- Load, failure, and upgrade testing.
- Support and incident-response procedures.

## Positioning

Start with private clouds, universities, security labs, and programmable
network environments. Do not position v1 as a global traffic-scrubbing service.
