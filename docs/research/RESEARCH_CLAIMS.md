# Research claims

## Supported claims

- The system detects high-rate traffic in an authorized OpenFlow 1.3 lab.
- The controller installs timed source-MAC drop rules.
- OpenFlow counters verify the installed rules.
- The dashboard provides explainable topology, flow, event, and mitigation views.
- The API provides authenticated access to local telemetry.

## Claims requiring benchmark evidence

- Runtime ML accuracy.
- Generalization to TCP, UDP, IPv6, or application-layer attacks.
- Low false-positive rates.
- Controller scalability.
- Production availability.
- Commercial DDoS protection.

## Research contribution

The defensible contribution is an evidence-first closed-loop SDN security
workflow that connects explainable detection to programmable enforcement and
verifies the result at the switch.
